# 코코 스터디 툴즈 (cocomate-study-tools)

컴퓨터활용능력 2급 실기 독학을 돕는 무료 도구 모음입니다.
Excel로 푼 모의고사 풀이를 정답 파일과 자동 비교해 채점하고,
학습 리포트(오답노트·취약점 진단)를 만들어 줍니다.

이 저장소는 도구 배포용입니다. 시험 문제·정답 등 학습 콘텐츠는
포함되어 있지 않습니다.

## 구성

| 파일 | 설명 |
|---|---|
| `grade.py` | diff 기반 자동 채점기. 문제/정답/풀이 파일을 비교해 100점 만점 채점 + 학습 리포트(HTML/JSON) 생성 |
| `코코채점.pyw` | 더블클릭용 채점 도구 (파일 선택 3번으로 채점) |
| `시험장.py` | 모의고사 런처 GUI (타이머·자동 채점·응시 기록·적응형 2주 일정·루틴 웹 연동 서버) |
| `코코시험장.pyw` | 시험장 더블클릭 실행 파일 |
| `기대값/*.json` | 세트별 채점 보정(배점·문제 그룹·제외 규칙 — 셀 주소와 점수만, 문제·정답 내용 없음). 도구가 자동으로 내려받아 세트에 연결 |
| `모의고사/*` | 코코 모의고사 1회·2회(자체 제작 연습 세트: `_문제.xlsx`·`_정답.xlsx`·`_문제지.pdf`). 시험장 2.3.1+가 `<설치 루트>/모의고사/`에 자동으로 내려받아 '코코 1회·2회' 일정 슬롯에 연결 |
| `루틴.html` | 2주 루틴 웹 페이지. 시험장 2.4.0+가 `시험장/루틴.html`로 내려받아 프로그램 안의 로컬 서버(`127.0.0.1:8765`)로 띄우고, 일정·기록·오답노트·체크 상태를 양방향으로 동기화([루틴 열기] 버튼). 파일로 직접 열거나 아티팩트로 열면 기존 localStorage 모드로 동작 |
| `version.json` | 자동 업데이트 메타데이터 (`files`·`data_files`·`set_files`·`sha256`) |

## 설치

1. Python 설치 (https://www.python.org/downloads/ — "Add python.exe to
   PATH" 체크, tcl/tk 포함)
2. `pip install openpyxl` (도구가 자동 설치를 제안하기도 합니다)
3. 파일을 받아 원하는 폴더에 두고 `.pyw` 파일을 더블클릭

## 사용법 (요약)

```
python grade.py --problem 문제.xlsx --answer 정답.xlsx --student 내풀이.xlsx
```

리포트는 풀이 파일 옆 `채점결과/` 폴더에 저장됩니다.
자세한 옵션(`--key`, `--html`, `--json`, `--history`)은 grade.py 도움말을
참고하세요.

## 자동 업데이트

도구는 **실행할 때마다** 이 저장소의 `version.json`을 확인(타임아웃 3초)해
새 버전이 있으면 **묻지 않고** 프로그램 4개와 `기대값/*.json`을 내려받아
검증(`sha256` 해시, `.py` 문법 검사, `.json` 파싱, 버전 일치)한 뒤 `.bak`
백업 → 교체 → 자동 재시작합니다(시험 진행 중이면 시험이 끝난 뒤). 검증에
하나라도 실패하면 아무 파일도 바꾸지 않습니다. 버전이 같아도 새로 추가되거나
바뀐 `기대값/*.json`은 내려받아 갱신하고, 이 저장소에서 사라진 기대값은
사용자 PC에서 지우지 않습니다. 네트워크가 없거나 저장소에 접근할 수 없으면
조용히 건너뜁니다.

- 끄기: 시험장 시작 화면의 [자동 업데이트] 체크박스(= `시험장/세트설정.json`의
  `"_설정": {"자동업데이트": false}`). [업데이트 확인] 버튼은 체크와 무관하게
  즉시 확인·적용합니다.
- 기대값 JSON은 `<설치 루트>/기대값/`에 저장되며, 문제 파일과 같은 폴더에
  같은 이름의 기대값이 있으면 그쪽이 우선입니다.
- 코코 모의고사 세트 파일(`set_files`, v2.3.1+)은 `<설치 루트>/모의고사/`에
  저장됩니다. `sha256`(필수)과 파일 머리(PK/%PDF)만 검사하며, 로컬에 없거나
  해시가 다르면 `.bak` 백업 후 갱신합니다.
- 루틴 페이지(`set_files`의 `"시험장/루틴.html"`, v2.4.0+)는 `시험장/루틴.html`에
  저장됩니다(`sha256` + UTF-8 검사). 시험장은 매 요청마다 파일을 읽으므로
  갱신이 재시작 없이 반영됩니다. 2.3.0 이하는 `set_files`를 무시합니다.

### version.json 형식

```json
{
  "version": "2.3.1",
  "notes": "변경 요약 (업데이트 후 시작 화면 띠에 표시)",
  "files":      {"시험장/시험장.py": "시험장.py", "채점/grade.py": "grade.py", "...": "..."},
  "data_files": {"기대값/코코모의고사1회_기대값.json": "기대값/코코모의고사1회_기대값.json"},
  "set_files":  {"모의고사/코코모의고사1회_문제.xlsx": "모의고사/코코모의고사1회_문제.xlsx",
                 "시험장/루틴.html": "루틴.html"},
  "sha256":     {"시험장.py": "<hex>", "기대값/코코모의고사1회_기대값.json": "<hex>", "모의고사/코코모의고사1회_문제.xlsx": "<hex>"}
}
```

`files`는 프로그램(.py/.pyw)만, JSON은 `data_files`에만 둡니다 — v2.2.3
이하의 업데이트 코드는 `files` 항목에 `__version__` 표식과 문법 검사를
요구해 JSON이 섞이면 전체 업데이트가 실패하기 때문입니다(구버전은
`data_files`·`sha256`을 무시하고 프로그램만 갱신한 뒤, 재시작된 새 버전이
기대값을 채웁니다). 같은 이유로 xlsx·pdf 같은 바이너리는 `set_files`에만
둡니다 — v2.3.0의 `data_files` 검증은 UTF-8 디코드와 JSON 파싱을 요구해
바이너리가 섞이면 2.3.0 사용자의 업데이트가 실패합니다(2.3.0 이하는
`set_files`를 무시하고 프로그램만 갱신한 뒤, 재시작된 새 버전이 세트 파일을
채웁니다). 루틴 페이지 HTML도 같은 이유로 `set_files`에 둡니다.
