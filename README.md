# 코코 스터디 툴즈 (cocomate-study-tools)

컴퓨터활용능력 2급 실기 독학을 돕는 무료 도구 모음입니다.
Excel로 푼 모의고사 풀이를 정답 파일과 자동 비교해 채점하고,
학습 리포트(오답노트·취약점 진단)를 만들어 줍니다.

이 저장소는 도구 배포용입니다. 시험 문제·정답 등 학습 콘텐츠는
포함되어 있지 않습니다.

## 구성

| 파일 | 설명 |
|---|---|
| `grade.py` | diff 기반 자동 채점기. 문제/정답/풀이 파일을 비교해 100점 만점 채점 + 학습 리포트(HTML/JSON) 생성 |
| `코코채점.pyw` | 더블클릭용 채점 도구 (파일 선택 3번으로 채점) |
| `시험장.py` | 모의고사 런처 GUI (타이머·자동 채점·응시 기록) |
| `코코시험장.pyw` | 시험장 더블클릭 실행 파일 |
| `version.json` | 자동 업데이트 메타데이터 |

## 설치

1. Python 설치 (https://www.python.org/downloads/ — "Add python.exe to
   PATH" 체크, tcl/tk 포함)
2. `pip install openpyxl` (도구가 자동 설치를 제안하기도 합니다)
3. 파일을 받아 원하는 폴더에 두고 `.pyw` 파일을 더블클릭

## 사용법 (요약)

```
python grade.py --problem 문제.xlsx --answer 정답.xlsx --student 내풀이.xlsx
```

리포트는 풀이 파일 옆 `채점결과/` 폴더에 저장됩니다.
자세한 옵션(`--key`, `--html`, `--json`, `--history`)은 grade.py 도움말을
참고하세요.

## 자동 업데이트

도구는 하루 1회 이 저장소의 `version.json`을 확인해 새 버전이 있으면
업데이트를 제안합니다. 네트워크가 없거나 저장소에 접근할 수 없으면
조용히 건너뜁니다.

## 라이선스 / 문의

개인 학습 용도로 자유롭게 사용하세요. 문제·정답 파일은 각자 준비해야
하며, 이 저장소는 어떤 시험 콘텐츠도 배포하지 않습니다.
